# 聚合分组 Key 与 Magpie 导入

## 创建与路由

API 密钥页勾选「创建聚合 Key」，直接添加 1–20 个当前用户有权使用的分组，可跨 OpenAI、Claude、Gemini 等平台。无需创建或选择普通 Key。支持搜索、删除和调整优先级；普通 Key 保留单分组行为。

服务端按顺序检查分组权限、状态、模型白名单、渠道限制及可调度账号的模型能力，选择第一个匹配分组。每次读取当前聚合配置、用户与分组权限，并重新检查订阅资格；没有匹配项时拒绝请求。

每次请求先按优先级选择分组，当前分组内账号重试耗尽后，可在未向客户端写入响应且未提交计费任务时切换下一个分组。支持明确的上游 429、500/502/503/504/529 及现有网关归类为可重试的连接故障；调度器确认账号池处于冷却、暂不可用时也继续选择。已输出的 SSE 内容或心跳、客户端断开、输入校验、认证/权限、余额、额度或本地限流错误不触发重放。

每次切换重新走完整认证与网关流程，重新检查目标分组权限、模型、订阅、余额、额度和并发；失败尝试返回后释放并发槽和在途余额预留。原分组的 legacy fallback 被关闭，只能按请求开始时固定的聚合列表向后尝试，每个分组至多一次，最多 20 个分组。管理员中途新增/重排分组不会改变当前请求的尝试顺序，删除或撤销权限仍立即生效。普通 Key 的单分组行为不变。

## 计费

一个聚合 Key 共用一份总额度和滚动限额。使用记录保留聚合 Key ID，Group ID 为实际使用分组。价格、用户专属倍率、高峰倍率、订阅及平台配额沿用所选分组的正常流程。不创建子 Key、不扣普通 Key 额度。跨分组尝试共用服务端生成的同一个计费请求 ID，失败且无用量的尝试不扣费，成功后按实际分组倍率只结算一次；一旦已提交用量计费，即使响应发生错误也禁止跨分组重放。全局用户 RPM 对一次客户端请求只递增一次，切换时仍读取当前计数并检查限制，每个尝试分组独立检查分组 RPM。

这里保证的是 Sub2API 本地账本不会因自动切换重复结算。连接中断等不确定结果下，第三方上游是否已经受理或自行收费无法由本站保证。流中途失败可能已产生用量，保留原分组正常计费，不能宣称这类失败一律免费。

## 支持范围

支持 HTTP Chat Completions、Responses 及已有别名、Messages/count_tokens、Gemini generateContent/streamGenerateContent/countTokens，包括 HTTP SSE。跨分组保持客户端请求的模型名，若两个分组使用不同上游模型 ID，需要通过各分组现有模型映射配置共同的公开模型名，不会擅自更换用户请求的模型。

`previous_response_id`、`conversation`、Gemini `cachedContent`、上传文件 ID/URI、向量库或容器等绑定上游的请求不自动跨分组重放；完整消息历史与内联缓存提示可以切换。只缓冲待重试的错误响应（上限 64 KiB），正常成功及流式数据立即传递，超过错误缓冲上限也停止重放。

WebSocket Responses 的模型在首帧才提供，本版明确拒绝聚合 Key。文件、批任务、图片/视频持久任务也使用普通 Key，防止后续资源访问跨分组归属错误。

`/v1/models` 返回所选可用分组的账号模型去重合集，应用白名单与渠道限制；`/v1beta/models` 只列原生 Gemini 路由适用模型。模型发现不发上游请求，也不选择计费分组。仅枚举明确模型 ID，不猜测未知通配符内容。

## 契约与迁移

创建：`is_aggregate: true, aggregate_group_ids: [groupId1, groupId2]`。数组顺序为优先级，持久化 `group_id` 为 NULL，仅请求副本带实际分组。更新使用 `aggregate_group_ids`，不能通过 `group_id` 修改聚合分组，也不能更新 Key 类型。

迁移 248 保留历史聚合字段，迁移 249 添加 `aggregate_group_ids`，将旧聚合 Key 的原分组转为一个直接分组并清空 `group_id`。旧成员列保留但不再参与调度或计费，普通 Key 和余额不变。认证快照版本同步更新。

## Magpie

导出本站 API 地址和当前这一个 Key，不含其他 Key。聚合 Key 导出 composite 协议集合：chat、responses、anthropic、gemini，模型由客户端自动发现。协议集合不表示自动跨协议转换，应使用模型支持的接口。

地址优先使用站点 API Base URL，否则使用浏览器 origin，本地预览导出本机地址。主入口是 `magpie://import`，官方备用页面为 `https://usemagpie.ai/import#...`，凭据在 fragment 中。链接包含凭据，请勿分享。

参考：<https://usemagpie.ai/docs/import>，<https://github.com/CallMeKingsley97/key-to-magpie>。

本地验证覆盖直接分组选择、排序、无普通 Key 创建、模型匹配、权限撤销、白名单、失效账号、并发上下文隔离、实际分组计费与日志归属、认证缓存、请求模型冲突与请求体回填。新增测试覆盖跨分组故障切换、冷却池跳过、权限撤销、请求体与上下文隔离、稳定计费 ID、流式/计费停止边界、并发隔离及全局 RPM 单次计数。本地模拟使用本机假上游与测试账本，无付费模型调用。前后端构建与预览结果以本次日志为准，不能视为生产部署验证。
